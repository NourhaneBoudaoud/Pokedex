# Pokédex

Final project for the InHolland React Native course: a Pokédex on the [PokeAPI](https://pokeapi.co), following the course Figma design.

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go.

- What the app is: [specs/product.md](specs/product.md)
- Features: [specs/features/](specs/features/)
- Instructions for the coding agent: [AGENTS.md](AGENTS.md)
- CI: [GitHub Actions](.github/workflows/ci.yml) runs lint, tsc and the tests on every push and pull request.
